# Contributing

Use TypeScript with strict schemas and documented exports. Run `npm run release:check` and `bun run release:check` before review. Tests use real SDK temp trackers with no Git requirement; at most two test workers run at once. Keep authoritative state in native records and use revision-guarded mutations.

Record work in this package's tracker, link files/docs/tests, and commit each item with its append-only history. Use explicit staged paths. Public fixtures and reports must contain only reviewed public data. Publication requires maintainer approval through the fleet release workflow.
